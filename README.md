## Project Overview

This project is a GUI-based Library Management System built using **Python and Tkinter**. It automates common library operations such as adding books, viewing records, searching books, issuing and returning books, and deleting entries.

All records are stored in a **CSV file**, enabling simple and permanent data storage.

## Features

* Add new books
* View all books in a table
* Search books by ID or title
* Issue books with borrower details
* Return issued books
* Delete book records
* Auto-save data using CSV file handling

## Technologies Used

* Python 3
* Tkinter (GUI)
* CSV File Handling
* Datetime Module

## How to Run the Project

1. Install Python on your computer
2. Download the repository
3. Open `library_gui.py`
4. Run the file
5. Use the GUI for adding, searching, issuing, returning, or deleting books
